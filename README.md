# 📊 USA Regional Sales Analysis Dashboard

An interactive **USA Regional Sales Analysis** project built using **Python and Power BI** to analyze sales, revenue, profit margins, products, customers, sales channels, regions, and states.

## 📌 Project Overview

This project analyzes Acme Co.'s **2014–2018 USA sales data** to identify key revenue and profit drivers across different products, sales channels, regions, and customer segments.

The project combines **Exploratory Data Analysis (EDA) using Python** with an interactive **Power BI dashboard** to convert raw sales data into meaningful business insights.

## 🎯 Objectives

- Identify top-performing products, regions, and sales channels.
- Analyze revenue, profit, and profit margins.
- Understand monthly and yearly sales trends.
- Identify seasonal patterns and unusual transactions.
- Analyze customer and regional performance.
- Identify opportunities for pricing, promotions, and market expansion.
- Present insights through an interactive Power BI dashboard.
